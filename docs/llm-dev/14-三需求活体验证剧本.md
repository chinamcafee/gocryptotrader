# 14 · 三需求活体验证剧本（上线实弹清单）

**定位**：三需求（①对话自然语言筛选 ②GUI 批量开仓决策 ③持仓复核）的**离线验证面已全部闭合**——`13-合约筛选与批量决策工作台.md` §5 状态批注 + workLog session-54 增量一~十三（含浏览器实测四段落与 mock 对话筛选全貌）。本文把剩余的**活体验证**（真模型 × 真 bot）整理成可直接照跑的步骤：新版 bot 重启后逐段实弹即可。

> 当前 9053 为**旧二进制**（不含新端点/新工具/新页数据面）——重启换成 llm-dev 分支构建的新版属用户运行态决策。

## §0 前置（一次配置）

1. **构建新版**：项目根 `make build`（或 `go build -o ./gocryptotrader ./`）。替换前停旧实例请自行确认运行态影响。
2. **配置项**（`config.json`，v19 迁移后自动带默认）：
   - `llm.enabled=true`；`llm.runMode` 建议先 `SHADOW`；
   - `llm.screener.flowScanLimit`（默认 100，硬上限 600）；
   - `llm.batch.maxMarkets`（默认 10，硬上限 50）；
   - `llm.risk.expectedMarginType`（默认 `CROSS`，decision 03=A）。
3. **密钥与配对**：vault 录入 LLM/Jev 密钥（`gctcli llm secrets`，只写不回显）→ 模型与配对页确认配对 `READY`。
4. **数据面成长期**：`llm.coverage.enabled=true` 后只读轮询开始（约占限频 2.4%）。**对话筛选的 T0（ticker）与 T1（K 线缓存）依赖这层缓存**——新启动后等一个整点全量重载或若干扫描周期，筛选才有数据（名单里的 `notes` 会如实说明缺席原因）。
5. **审批与授权**：策略工作区冻结一个版本（`FROZEN`）→ 授予**活跃审批**（账号=配置 accountId、网络=测试网）→ 市场授权页给目标合约授上。批量与复核都会强校验这三件。

## §1 需求①·对话筛选（真模型）

- **步骤**：对话页新建会话 → 发例如：「帮我筛选 24h 涨幅大于 5%、4h 也上涨、MACD 为 BULL 的前 10 个合约」。
- **预期**：模型自主调用 `screenMarkets` → 回复给出命中合约列表与数据 → 证据卡 `tool:screenMarkets:*`（质量 `DATABASE_CACHED`）。列表按命令排序、TopN 生效。
- **排障**：
  - 模型不调工具 → 所用模型修订版需支持 function calling（换强 tool-use 模型）；工具 description 已带"何时使用"触发句（session-54 续七）。
  - 结果为空 → 看回复里的 `notes`：宇宙规模/缺席计数（K 线未入缓存或 T2 未覆盖）——等缓存或调 `flowScanLimit`。
  - 指标认不出 → 用 `LLMGetScreenerMetrics` 目录里的名字（12 指标：`lastprice`/`change24h`/`quotevolume24h`/`change4h`/`change48h`/`atrpercent`/`range24h`/`macdstate`/`macdhist`/`macdcross`/`takernetflowratio24h`/`takernetflow24h`）。

## §2 需求②·GUI 批量开仓决策

- **步骤**：筛选与开仓决策页 → 运行筛选 → 勾选命中行 → 版本下拉（活跃审批自动预选，A5）→「对选中 N 个生成开仓决策」→ 轮询进度。
- **预期**：逐行 `DONE` + 裁决（`HOLD`/`OPEN_*`）+ `decisionRunId`；到决策与审计页可查列表与血缘（十步链）。
- **说明**：**只记录不下单**（与 trigger/preview 同级承诺）；方向由分析链产出（A8 默认）；SHADOW 链永不成单。
- **排障**：起批被拒=无活跃审批/版本非 `FROZEN`/市场数超上限——错误文本会指路；单市场也可用页内输入框直接发起。

## §3 需求③·持仓复核

- **步骤**：持仓决策页 → 确认 venue 持仓行（数量/方向）→ 勾选、全量按钮或单市场输入 →「生成持有/平仓决策」。
- **预期**：逐行 `DONE`；决策血缘抽屉里复核消息块含：自开仓窗口（涨跌/最大不利偏移/区间振幅）、**资金费累计**、**保护性止损现状**（PLACED at 价位 / none on record / unavailable 如实标注）。
- **排障**：场地读不到持仓即拒（复核不存在的仓位是伪造语境）；开仓时刻读不到时以 48h 兜底并**如实标注 fallback**。

## §4 安全与运行纪律

- 验证期间保持 `SHADOW`/`READ_ONLY` 读链；运行模式切换走「健康与治理」页（写操作受代理写闸 `GCT_ALLOW_WRITES` 控制，本地 mock 栈测后必须恢复 false）。
- 前端本地联调配方（mock 栈三件套）见 `taskProgress/README.md`；生产网关 9053。
- 任何一段失败请带 engine 日志（`llm` 子系统）与该步的决策 `runId` 回报——离线夹具已覆盖的分支可直接对照 workLog session-54 定位。
