# 阻塞决策（必须用户拍板）

本目录存放**必须用户决策否则会阻塞**的事项。**一项一文件**，命名 `<序号>-<短横线短语>.md`。

## 写入规则

1. 只在**确实无法自行判断**且**不决策就无法继续**时才写入本目录
2. 写入后在 `TASKS.md` 把对应任务标为 `[!]`，并**跳过它继续做其它不阻塞的任务**
3. **不要停下来等用户** —— 除全部剩余任务都被阻塞外，必须持续推进
4. 用户决策后：把结论回写技术方案文档 → 更新 `TASKS.md` 状态 → 在本文件列表里标记已解决

## 模板

```markdown
# <序号>. <一句话问题>

**阻塞的任务**：TASKS.md 中的 ID
**为什么必须你决定**：（说明为何模型无法自行判断）
**背景**：（现状、涉及的技术文档章节）
**可选项**：（2-4 个，含取舍分析）
**我的建议**：（推荐哪个及理由）
**如果不决策的后果**：（能绕过吗？绕过会怎样？）
```
